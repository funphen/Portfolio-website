# funphen — портфоліо

Статичний сайт без збірки: достатньо покласти файли на GitHub Pages.

## Структура

```
index.html          розмітка сайту (тут же пошта та посилання на LinkedIn)
css/style.css       стилі
js/content.js       ← ВЕСЬ КОНТЕНТ: проєкти, роботи, тексти, фото, відео
js/main.js          логіка сайту (зазвичай не чіпати)
assets/images/      ваші фото та картинки
assets/video/       короткі відео (за потреби)
```

## Як опублікувати на GitHub Pages

1. На github.com натисніть **New repository**. Назвіть його, наприклад, `portfolio` (або `ваш-нік.github.io`, тоді сайт буде за адресою `https://ваш-нік.github.io`).
2. Завантажте в репозиторій **вміст цієї папки** (**Add file → Upload files**), так щоб `index.html` лежав у корені.
3. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, натисніть **Save**.
4. Через 1–2 хвилини сайт буде доступний за адресою, яку покаже GitHub угорі сторінки Pages.

Оновлення сайту: змінюєте файли в репозиторії (або завантажуєте нові), і сайт оновлюється автоматично.

## Як додати роботу

1. Покладіть фото в `assets/images/`.
   - Назви файлів латиницею, без пробілів, наприклад `cover-1.jpg`.
   - GitHub Pages розрізняє великі й малі літери: `Cover-1.JPG` і `cover-1.jpg` це різні файли.
   - Ширина до 2000 px, формат JPG або WebP, бажано до 500 КБ на фото.
2. Відкрийте `js/content.js`, знайдіть проєкт і впишіть йому `works`:

```js
{
  name: T('Обкладинки', 'Covers'),
  works: [
    {
      title:   T('Обкладинка альбому', 'Album cover'),
      img:     'assets/images/cover-1.jpg',
      images:  ['assets/images/cover-1-b.jpg',
                { src: 'assets/images/cover-1-c.jpg', full: true }],
      year:    2026,
      tools:   'Photoshop',
      task:    T('Завдання…', 'Brief…'),
      process: T('Процес…', 'Process…'),
      result:  T('Результат…', 'Result…')
    }
    // ...наступна робота
  ]
}
```

Усе, крім `title`, необов'язкове. Блок тексту, якого немає, не показується.

## Відео

У полі `video` можна вказати:

- посилання на **YouTube** або **Vimeo**: `video: 'https://www.youtube.com/watch?v=XXXXXXXXXXX'`. Відео відтворюється прямо на сторінці роботи, а в сітці автоматично з'являється його прев'ю (якщо не задано `img`);
- власний файл: `video: 'assets/video/clip.mp4'`. Для GitHub краще ролики до 25 МБ (кожен файл має бути менше 100 МБ). Для довгих відео використовуйте YouTube або Vimeo.

## Стрічка фото під категоріями

У `js/content.js` додайте шляхи до фото в `SITE.reel`. Порожній список залишає сірі плитки.

## Контакти та інше

- Пошта і LinkedIn: знайдіть їх у `index.html` (рядки з `mailto:` і `linkedin.com`).
- Назви категорій і проєктів: `js/content.js`, поле `name`/`title` (дві мови через `T('укр', 'eng')`).
